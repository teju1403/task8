# Sales Dashboard – Task 8

##  Description
This project is part of my Data Analyst Internship. The goal was to create a simple and clear sales dashboard using Tableau.

##  Dataset Used
- Name: Sample - Superstore.csv
- Columns used: Order Date, Sales, Profit, Region, Category

##  Tools
- Tableau Public

##  What I Did
1. Loaded the CSV file into Tableau.
2. Changed the Order Date to show Month-Year.
3. Created:
   - A line chart for monthly sales
   - A bar chart for sales by region
   - A donut chart for sales by category
4. Added a filter for Region.
5. Built a dashboard combining all charts.

##  Insights Found
- The West region had the highest overall sales.
- Technology was the top-selling category.
- Sales peaked in December.
